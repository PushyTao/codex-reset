### 通过的端到端验证

1. 应用与 SMTP 容器健康检查通过。应用 uid=1000（node），cap_drop=ALL，no-new-privileges=true。
2. 宿主机访问映射端口：首页、`/admin`、CSS、JavaScript、`/healthz` 均返回 HTTP 200。
3. 后台未登录返回 401；登录有效；缺少 CSRF、跨来源写入返回 403；公开 API 不暴露邮箱/SMTP 配置。
4. 随机管理员密码、AES 密钥权限为 0600；SMTP 密码加密入库且不回显。
5. 完整生产邮件链路：保存 SMTP → 测试邮件 → 手动录入隔离测试重置 → 生产定时工作器发送 → SMTP 接受与发送日志一致。
6. SMTPS 与 STARTTLS 均完成 TLS 证书验证和 SMTP 账号认证；拒绝不支持 TLS 的明文服务器。
7. 重复提交相同原帖返回 409，不生成重复邮件。
8. 强制重建应用容器后，SQLite、邮箱、配置、密钥及随机密码完整保留；旧会话失效，重新登录正常；已发送消息没有重发。
