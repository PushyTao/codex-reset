# 1.1.0 验收记录

验收日期：2026-10-28（北京时间）。

本页记录 1.1.0 当次发布的验收结果和摘要；`latest` 会随新版本更新，当前部署版本见 [README](../README.md)。

## 变更

- 新预告和正式重置分别提醒一次，按来源身份、通知阶段和收件邮箱持久化去重。
- 预告时间、原文或已证实来源别名变化不重复发信；正式重置沿用预告时间或换用新的公告 ID 时仍能处理。
- 历史与状态接口分别同步和退避；历史不可用时状态快照仍可提醒，但不会越过未导入的历史基线。
- 确认完成或撤下的预告取消未发送任务。发送中断、回执不明标为“结果待确认”，避免自动重发。
- 后台日志展示通知阶段和待确认状态；原有数据自动增补字段，保留投递历史。
